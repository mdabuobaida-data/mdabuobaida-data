### 🚀 Featured Projects

#### 📊 [Sarita Store – Retail Sales Analysis (Excel)](https://github.com/mdabuobaida-data/sarita-store-sales-analysis)
End-to-end analysis of a real e-commerce sales dataset with **31,000+ orders** across channels like Amazon, Flipkart, Myntra, Ajio, and Meesho.
- Cleaned and structured raw order-level data (customer, product, shipping, and pricing fields)
- Built pivot tables to break down sales by **category, channel, state, and month** (Jan–Dec 2022)
- Tracked ₹2.1 Crore+ in total order value across 8 product categories (Saree, Kurta, Western Dress, and more) and 50 shipping states
- **Skills:** Excel, Pivot Tables, Data Cleaning, Formulas, Charts

#### 📈 [Sales & Profit Dashboard (Power BI)](https://github.com/mdabuobaida-data/sales-profit-dashboard)
Interactive Power BI dashboard analyzing order-level sales and profit performance over time.
- Built a data model connecting **Orders** and **Order Details** tables
- Designed visuals to track **Sum of Profit by Month** using a Date Hierarchy
- Enabled drill-down analysis from yearly → monthly trends for quick business insights
- **Skills:** Power BI, Data Modeling, DAX, Interactive Visuals
